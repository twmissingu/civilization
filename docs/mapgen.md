# 地图生成（Map Generation）

> 状态：M1 切片定稿项 = 噪声算法/seed 确定性/海拔湿度分桶；具体参数值标 `默认`，M2 调优。
> 来源：jiuqing-roles-debate M1 启动可行性评估者提案 + 第 2 轮评审收敛。

---

## 1. 算法

- **Simplex 噪声**（确定性，接受 seed）。Perlin 备选但 Simplex 各向同性更优。
- 两路独立噪声 fork：`rng.fork('elevation')` 与 `rng.fork('moisture')`。
- 海拔与湿度独立生成后组合映射到地形。

## 2. 参数（默认，M2 调优）

```
octaves = 5
frequency = 1 / 64        // 低频大尺度
persistence = 0.5
lacunarity = 2.0
```

## 3. 海拔分桶（-> 地形）

| 海拔范围 | 地形 |
|---------|------|
| < 0.30 | 海洋 |
| 0.30 – 0.38 | 海岸 |
| 0.38 – 0.55 | 草原 / 平原（由湿度区分） |
| 0.55 – 0.65 | 丘陵 |
| 0.65 – 0.75 | 丘陵（资源倾向） |
| > 0.75 | 山脉 |

- 海拔 > 0.65 且 < 0.75 也可标丘陵；> 0.75 为山脉（不可通行）。
- 海岸为海拔 0.30–0.38 的水陆过渡格。

## 4. 湿度分桶（修饰草原/平原/沙漠/冻土/雪原）

| 湿度范围 | 修饰（在草原/平原海拔段） |
|---------|------------------------|
| < 0.25 | 沙漠 |
| 0.25 – 0.50 | 平原 |
| > 0.50 | 草原 |

- 纬度（r 坐标）修正：r 接近 0 或 35（南北极）-> 冻土/雪原覆盖，忽略湿度。
  - |r - 17.5| > 14（极区）：高海拔->雪原，低海拔->冻土。

## 5. 特征分布（叠加在地形上）

| 特征 | 分布概率 | 限制 |
|------|---------|------|
| 森林 | 0.20 | 草原/平原/冻土/丘陵 |
| 雨林 | 0.12 | 平原（热带纬度） |
| 沼泽 | 0.06 | 草地/泛滥（沿河） |
| 地热裂缝 | 0.03 | 任意非海洋 |
| 绿洲 | 0.02 | 沙漠 |
| 泛滥平原 | 沿河 | 河流相邻草地/平原 |

- 特征分布用 `rng.fork('features')`，每格独立判定。
- 河流：从海拔 > 0.65 格向海拔 < 0.38 格求最陡下降路径，沿路径标记河流边（6 方向）。

## 6. 资源分布

| 资源类别 | 分布 |
|---------|------|
| 加成（牛/羊/稻/麦/铜/石头） | 0.10 概率，依附地形（牛/羊->草原/平原，铜/石头->丘陵） |
| 奢侈（香料/丝绸） | 0.04 概率，依附特定地形/特征 |
| 战略（铁/马/硝石） | 0.05 概率，铁->丘陵，马->草原/平原，硝石->平原（受限时代解锁） |

- 资源分布用 `rng.fork('resources')`。

## 7. 确定性保证

- 全部随机经 `rng` 子流（elevation/moisture/features/resources），不调 `Math.random`。
- 同 seed + 同 `GameConfig.mapSize` 产出完全相同地图（CP-02 测试断言）。
- 地图边界 q ∈ [0,59]、r ∈ [0,35]；边缘外视为不可通行（不生成）。

## 8. 大陆/海洋比例

- MVP 默认海平面 0.30，目标陆地占比 ~55–65%。若实测偏差大，M2 调海平面阈值。
- 不做"大陆形状"预设系统（如 'pangaea-4p'）--测试用尺寸+seed 生成，预设系统留待 Phase 2。
