# 完整版实现计划（Phase 2-5）

> 当前：Phase 1 MVP v0.2.0 已发布（3 文明/34 科技/7 区域/8 政体/3 胜利/AI/存档/PixiJS/94 资产/121 测试）。
> 北极星：文明6 基础版全机制。本计划从第一性原理出发，按依赖序排列。

## Phase 2：核心扩展（城邦/大人物/贸易/宗教/文化胜利）

### 2.1 城邦系统
- 数据：`src/gamedata/citystates.ts`（~12 城邦，分类：文化/科技/军事/经济/宗教，各自宗主国加成）
- 逻辑：`src/logic/state/citystate.ts`（使者分配、宗主国判定、城邦加成计算）
- 渲染：城邦在城市面板显示，使者分配 UI
- AI：AI 争夺城邦宗主国（ai-design 扩展）
- 测试：CP-13 城邦使者分配 + 宗主国加成

### 2.2 大人物
- 数据：`src/gamedata/greatpeople.ts`（大将军/大科学家/大工程师/大商人/大艺术 家，各自效果）
- 逻辑：`src/logic/state/greatpeople.ts`（按伟人点积累积、招募、使用）
- 渲染：侧栏伟人点显示 + 招募按钮
- 测试：CP-14 伟人招募 + 效果

### 2.3 贸易路线
- 逻辑：`src/logic/state/trade.ts`（商人单位建立路线、自动产出、道路铺设）
- 渲染：路线可视化（连线）
- 测试：CP-15 贸易路线建立 + 产出

### 2.4 宗教系统
- 数据：`src/gamedata/religion.ts`（万神殿/传教士/使徒/宗教胜利）
- 逻辑：`src/logic/state/religion.ts`（信仰购买、传教、宗教压力、宗教胜利）
- 信仰值从"仅计分"改为可消费（购买单位/建筑）
- 渲染：宗教面板、传教范围
- 测试：CP-16 宗教传播 + 宗教胜利

### 2.5 文化胜利 + 完整政体/区域
- 文化胜利：旅游业绩系统（`src/logic/state/tourism.ts`）
- 补齐：机场区域、后期政体、全部奇观
- 测试：CP-17 文化胜利

**Phase 2 验收**：5 种胜利全可达成、城邦/大人物/贸易/宗教全机制可玩。

## 技术债（优先清理）

| 项 | 影响 | 优先级 |
|---|------|--------|
| canExecute/applyCommand 大 switch | 维护成本 | 中（Phase 2 前抽 per-kind handler） |
| Pixi 全量重绘 | 大地图性能 | 高（Phase 3 前做视口剔除） |
| AI aiDecide 大函数 | 可维护性 | 中（抽战略/战术子模块） |
| 美术 94/~250 | 视觉完整度 | 持续补齐 |
| structuredClone 每命令 | AI 回合性能 | 低（当前 <13ms/回合，够用） |
