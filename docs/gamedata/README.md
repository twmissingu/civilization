## 7. 战斗力公式与伤害结算（确定性）

```
有效战斗力 CS_eff = CS_base
  + 地形修正      (防御方：丘陵 +2, 森林/雨林 +1; 攻击方跨河 -1)
  + 夹击修正      (攻击方每侧翼友军 +2, 最多 +4)
  + 支援修正      (防御方每相邻友军 +2, 最多 +4)
  + 晋升修正      (每级 +5)
  + 政策修正      (按政策卡定义, 如谋略 +4 近战)
  + 血量修正      (HP < 100 时: -floor((100 - HP) / 5))

伤害（确定性）:
  CS_diff = CS_attacker - CS_defender
  base_damage = round(30 * e^(CS_diff / 25))   // 注：e^ 用查表或定点近似实现，禁浮点累计
  damage = clamp(base_damage, 10, 100)
  (MVP 用种子化 RNG 做 ±5 波动, 种子 = hash(turn, attackerId, defenderId))

近战: 攻击者对防御者造成 damage; 防御者对攻击者造成 counter_damage
      (counter_damage = 同公式但 CS_diff 取反, ×0.5, 向下取整)
远程: 攻击者对防御者造成 damage; 无反击
```

### 7.1 城市防御

```
城市 CS = max(驻军 CS, 10 + 城市人口)
城市 HP = 200（基础）, 城墙额外 +200 HP（古代城墙）/ +300 HP（中世纪城墙）
城墙壁垒 HP 归零前, 城市本体 HP 不受伤害
城市远程反击: CS = 城市 CS, 射程 1, 每回合 1 次（需城墙）
攻城单位效果:
  攻城塔: 近战攻击绕过城墙, 直接打城市 HP
  攻城武器(投石机/大炮): 远程对城墙造成全额伤害（普通远程减半）
```

### 7.2 ZOC 与堆叠

- ZOC 施加者：近战、骑乘、海军近战（远程/支援不施加）。进入敌方 ZOC 格须停步（消耗剩余移动力）。拥有"无视 ZOC"晋升者不受影响。
- 堆叠：每格最多 1 军事 + 1 平民/支援（MVP 平民：建造者/开拓者）。城中心格同规则。同格军事可主动攻击，平民不可。

## 10. 胜利条件

### 10.1 科技胜利（航天三段）

航天三段为**城市项目**（非科技）；科技节点为其前置：

```
阶段 1 发射卫星（项目）: 前置科技=火箭技术; 需大学; 成本=900 产能
阶段 2 登月（项目）:     前置=阶段1 + 科技"卫星"; 成本=1200 产能
阶段 3 火星殖民（项目）: 前置=阶段2 + 科技"纳米技术"; 成本=1500 产能; 完成即科技胜利
```

> 注："登月"是项目阶段名，不是科技节点；解锁登月项目的前置科技是"卫星"。

### 10.2 统治胜利

占领全部其他文明的原始首都。

### 10.3 分数胜利

```
分数 = 城市数 ×5 + 总人口 ×1 + 已研究科技数 ×3 + 已建奇观数 ×10
     + 总领土格数 ×0.5 + 已完成市政数 ×3 + 累积信仰值 ×系数（封顶防滚雪球）
默认回合上限: 300；到达上限分数最高者获胜
```

> 信仰值计入分数（范围裁决），不做主动消费。

## 11. 城市增长 / 住房 / 宜居度 / 文化扩张

### 11.1 人口增长
```
所需食物 = 15 + 8 × (当前人口 - 1)   (人口1需15, 人口2需23, ...)
每回合食物净产出累加, 达阈值 +1 人口, 溢出保留
住房不足(人口 ≥ 住房): ×0.5;  ≥ 住房+2: ×0.25;  ≥ 住房+4: ×0（停止）
```

### 11.2 住房来源
城中心 +2（初始）；粮仓 +2；水渠 +2；图书馆 0；每种区域 +0.5（累计向上取整）；建筑按表。

### 11.3 宜居度
```
每种奢侈资源 +4（文明范围, 非每城）；每种娱乐建筑 +1
每城需求 = floor(人口 / 2)
宜居度 = 总来源 - 总需求
叛乱(MVP 简化): 宜居度 ≤ -1 时每回合 5%×|amenity| 概率触发, 产出 -50% 持续 3 回合（不刷蛮族）
                宜居度 ≤ -3 时额外人口 -1（流失）
```

### 11.4 文化扩张
```
扩张到下一格所需文化 = 5 × (已扩张格数 + 1)   (第1格建城时免费, 第2格5, 第3格10...)
地块选择算法:
  1. 候选 = 城中心 3 格内未归属地块
  2. 按到城中心的曼哈顿距离排序(最近优先)
  3. 同距离优先级: 资源 > 丘陵 > 森林 > 平原 > 草原 > 沙漠/雪原
  4. 同优先级取格子坐标 hash 最小者(确定性)
金币买地: 价格 = 50 × (1 + 距城中心距离 × 0.5) × (1 + 已购买地块数 × 0.1); 仅可购买城中心 3 格内
```

### 11.5 区域人口门槛
```
区域数量上限 = floor(城市人口 / 3) + 1   (人口1-3: 1个; 4-6: 2个; 7-9: 3个...)
```
